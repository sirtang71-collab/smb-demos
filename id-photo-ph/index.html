🇵🇭 Philippines ID Photo Maker

Forms get returned when your photo is the wrong size or the wrong file size. This tool crops your photo to the exact pixel size and lands the file inside the KB window your form asks for — 2×2 in for e-Visa, visa and NBI, 1×1 in for IDs, and 3.5×4.5 cm for the Philippine passport.

🔒 100% processed on your device. No upload, no server, no tracking.

Sizes at 300 DPI: 2×2 in = 600×600 px · ≤240 KB (visa) · 1×1 in = 300×300 px · Passport 3.5×4.5 cm = 413×531 px. KB limits other than the visa 2×2 are editable defaults — always check the latest notice from the office you are applying to.

Philippine passport — read first: if you apply in the Philippines, do not bring a photo — the DFA captures your portrait on site during your appointment. The passport preset here is only for overseas / consulate applications that still ask for printed photos. Background: the current DFA ePassport spec is plain white; older guides asked for royal blue — that spec is superseded, so use white unless your consulate still asks for blue. No separate work-permit size: no distinct published work-permit photo size was found — notices ask for 2×2 or passport size, so use those presets.

How the minimum KB is reached honestly (when the office sets one): first the JPEG quality is raised to the highest level that still fits the limit. If the file is still under the minimum, the tool adds standard JPEG padding data — the picture does not change at all, no blur, no noise — and the message will say so when padding was used. If too much padding would be needed (your original is too small), the tool refuses instead of handing you a file that would be rejected.
