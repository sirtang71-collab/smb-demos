How the minimum KB is reached honestly: first JPEG quality is raised to the maximum that fits. If the file is still below the form's minimum, standard JPEG padding data is added — your picture itself is never altered, blurred or noised, and the export message tells you when padding was used. If a file would need absurd amounts of padding (a tiny thumbnail instead of a real photo), the tool refuses and tells you why.
