How a minimum KB is reached honestly (when your notice sets one): first JPEG quality is raised to the maximum that fits. If the file is still below the minimum, standard JPEG padding data is added — your picture itself is never altered, blurred or noised, and the export message tells you when padding was used. If a file would need absurd amounts of padding (a tiny thumbnail instead of a real photo), the tool refuses and tells you why, instead of handing you a file the portal would reject.
